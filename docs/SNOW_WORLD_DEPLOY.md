# Снежный переполох V2 — установка

Обновляются кабинет и только необходимые модули API. Не переключайте серверного бота с вашей main на xsg-snow-2026.

На сервере выполните:

```bash
sudo bash <<'BASH'
set -euo pipefail
umask 077
cabinet=/home/user1/bedolaga-cabinet
git -c safe.directory="$cabinet" -C "$cabinet" fetch https://github.com/XSGGH/bedolaga-cabinet.git xsg-theme
script=$(mktemp /root/xsg-snow-deploy.XXXXXX.sh)
git -c safe.directory="$cabinet" -C "$cabinet" show FETCH_HEAD:scripts/xsg-deploy-snow.sh > "$script"
bash "$script"
BASH
```

Скрипт сохраняет образы обоих работающих контейнеров (с docker commit, если исходный образ исчез), исходники, локальные настройки, compose, конфигурацию события и PostgreSQL dump в /root/xsg-snow-backups/<дата-время>. Сборки и HTTP-проверка нового образа проходят до замены работающих контейнеров. Настройки nginx и серверная main сохраняются; неизвестные интеграционные якоря/конфликты останавливают установку.

После успеха открыть /admin/snow-event. В разделе Квазара выбрать реальный «Гипердрайв» и подтвердить серверную проверку безлимитных и специальных сквадов. До этого оформление Квазара закрыто. Затем открыть предпросмотр, проверить нужные даты и состояния подписки; настройки можно полностью скрыть.

Старые правила события мигрируются только до 1 декабря и при нулевом реальном заработке. Если уже есть боевой прогресс старой версии, скрипт остановится: нужен отдельный согласованный перенос экономики. Он не пересчитывает настоящие балансы автоматически.

Откат к последней успешной резервной копии:

```bash
sudo bash <<'BASH'
set -euo pipefail
backup=$(cat /root/xsg-snow-backups/last-backup)
bash "$backup/deploy-script.sh" --rollback "$backup"
BASH
```

Возвращаются образы, изменённые файлы API, nginx и сохранённая конфигурация мероприятия. Пользовательская БД не откатывается целиком: подписки, оплаты, прогресс и постоянные права не уничтожаются. При неуспешном деплое предусмотрен автоматический откат; точный каталог напечатан в выводе. last-backup указывает на последний УСПЕШНЫЙ деплой, а не на неудачную попытку.

Подарочные часы/дни добавляются к end_date без списания денег и без изменений существующего биллинга. Денежные операции, настройки автопродления и история оплаченных периодов не меняются. На данном сервере только тарифы с оплатой периода — подтверждено владельцем. Отдельный механизм суточных кредитов отсутствует.

Локально проверены FastAPI/SQLite, все десять игр через Chrome, размеры 320/375/390/430/1280/1440/1920, даты/подписки/25 этапов, подарки Орбиты, Квазар и сохранение оплаченного времени, автоматический старт МСК, сборка и настоящий Nginx. Боевой PostgreSQL, Docker и синхронизация с реальной VPN-панелью проверяются при установке; доступа к серверу из этой среды нет.
