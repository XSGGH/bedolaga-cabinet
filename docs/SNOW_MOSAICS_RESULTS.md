# Три маленькие истории — результат реализации

Новая пользовательская часть заменяет зимнюю станцию: три книжные иллюстрации, общая мозаика из 224 частей, одна серверная игра на 12 карточках, личные подарки и постоянное нижнее меню. Старые 3D-компоненты, строительство, сравнение, голосование, украшения, маршрут Квазара и десять игр удалены из пользовательского интерфейса. Неиспользуемые исходники удалены. Прежние игровые API закрыты кодом410; история и финансовые данные сохраняются.

Личная награда: лучший результат дня10/20/30❄, до трёх попыток, при улучшении только разница. Общий вклад: один успешный день даёт один фрагмент/10общих❄ отдельно от кошелька. Главы72/72/80 открываются1/11/21декабря; последние части и развязка третьей истории —31декабря. Излишки учитываются в резерве, дополнительные истории24/32/40 публикуются через админку после подготовки изображения. Аудит хранит причину и администратора. Цели фиксированы.

Проверки:

- 40 интеграционных тестов FastAPI/SQLAlchemy/SQLite проходят: права, даты, повторные начисления, конкуренция на последнем фрагменте, резерв, подготовка бонусного арта, финансовые гарантии подарков, установка и сохранение локальных интеграций.
- 9 доменных тестов проходят: 5/8/10/25/100 игроков, уникальность224частей, лучшие награды, идентификаторы ходов, дата Москвы, резерв и аудит.
- Chrome:320/360/375/390/430/768/1440px; отсутствие горизонтального скролла, видимость меню при прокрутке, отображение доступных изображений. Полная партия с30❄, диалог подарка без лишнего выбора подписки, даты и статусы подписки, админка и прежний публичный анонс.
- TypeScript,Vite production build,Ruff,Biome и синтаксис Bash проходят. Защищённые SnowEventTeaser.tsx и snow-teaser.css не изменены.

Локальные доказательства: bedolaga-context/verification/snow-mosaics. Границы: тесты используют настоящие локальные SQLite/FastAPI и Chrome, с тестовыми границами авторизации/внешней VPN-панели. Боевой PostgreSQL,Docker и VPN-панель из этой среды не запускались. Production не развёртывался. При установке скрипт выполняет свои проверки и создаёт бэкап/откат.

Исходники иллюстраций и промпты находятся в API-репозитории: docs/SNOW_MOSAIC_ART.md и resources/snow-mosaics. На сайт исходники целиком не выкладываются: открытые фрагменты выдаются авторизованными запросами. Бонусные изображения сохраняются в постоянном data/snow-mosaics.

Деплой с бэкапом и откатом: [SNOW_MOSAICS_DEPLOY.md](SNOW_MOSAICS_DEPLOY.md). Нужен совместный API v3 и кабинет; прежний frontend-only деплой не подходит для смены механики.
