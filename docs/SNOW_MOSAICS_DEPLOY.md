# Установка «Семи планет: поиск Уголька» с бэкапом и откатом

Нужен совместный выпуск кабинета и API v4. Frontend-only скрипт для этого перехода не используйте. Ничего автоматически на production не запускалось.

```bash
sudo bash <<'BASH'
set -euo pipefail
umask 077
cabinet=/home/user1/bedolaga-cabinet
git -c safe.directory="$cabinet" -C "$cabinet" fetch https://github.com/XSGGH/bedolaga-cabinet.git xsg-theme
script=$(mktemp /root/xsg-snow-deploy.XXXXXX.sh)
git -c safe.directory="$cabinet" -C "$cabinet" show FETCH_HEAD:scripts/xsg-deploy-snow.sh > "$script"
bash "$script"
BASH
```

Скрипт сохраняет образы, исходники, nginx/compose, конфигурацию и PostgreSQL dump в `/root/xsg-snow-backups/<дата-время>`. Образ работающего контейнера сохраняется даже при удалённом исходном image. Локальная main бота не заменяется веткой разработки: накладываются только модули события и 264 закрытых WebP-фрагмента. Настройки nginx сохраняются. Сборки и проверки происходят до замены контейнеров; при ошибке предусмотрен откат.

После успеха: `/admin/snow-event`, предпросмотр нужных дат/подписок. На публичном `/snow-event` до1декабря останется прежний нейтральный анонс. С наступлением старта игровой интерфейс откроется по серверному времени.

Откат последнего успешного выпуска:

```bash
sudo bash <<'BASH'
set -euo pipefail
backup=$(cat /root/xsg-snow-backups/last-backup)
bash "$backup/deploy-script.sh" --rollback "$backup"
BASH
```

Для неудачной попытки используйте точный каталог из её вывода: last-backup указывает на последний успешный деплой. Образы и файлы возвращаются; пользовательская БД целиком не откатывается, оплаченные подписки/балансы/история сохраняются. Новые мозаики остаются в отдельном namespace. Не выполнять глобальный git reset/clean на сервере.

Дополнительные истории настраиваются через админку:черновик24/32/40частей→художественныйисходник→подготовкафрагментов→active:true. Опубликованную цель менять нельзя. Внеситеописательнуюпричину:операциипопадутваудит. Файлыбонусоввсуществующемпостоянномтомеdata/snow-mosaics;резервные копиитома сохранятьвместесданнымиприложения.


Выпуск переносит общий прогресс трёх мозаик в семь планет с архивом прежнего мира. Личные балансы, чеки, лучший результат дня, оплаченный срок и автопродление не меняются. Цель — 264 части, следующая глава открывается немедленно. После финала включаются огоньки дороги домой. В админском предпросмотре доступны все семь планет, проценты раскрытия и резерв.

При откате не восстанавливайте всю пользовательскую БД без отдельного решения: это может потерять новые покупки. Сохранённый установщик возвращает образы и исходники; прогресс и финансовая история остаются. Старый интерфейс может временно не показывать семь новых глав. Повторная установка v4 распознаёт и нормализует вклады, сделанные старым образом.


HTTP-проверка нового образа проверяет актуальные winter-hero.webp и snow-gift-atlas.png с побайтовым сравнением ответа nginx и файла в контейнере. Удалённые картинки станции в проверку не входят. Один только HTTP 200 не считается успехом: отсутствующая картинка может вернуть HTML страницы через SPA fallback. Если прежняя проверка остановилась до переключения контейнеров, повторите обычную команду выше — она возьмёт исправленный скрипт и создаст новый бэкап.
